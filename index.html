What I do for you

three ways I usually help
01 — build

Build you a pipeline

If your data lives in scattered files and manual exports, I'll design a proper ETL pipeline that pulls it all together.

  • CSV, Excel, and API sources
  • PostgreSQL, Oracle, MySQL
  • Docker-based, reproducible
02 — clean

Clean up your data

Duplicates, broken dates, negative prices, inconsistent names — I've seen it all. I'll make your data actually trustworthy.

  • Automated validation rules
  • Deduplication and type fixes
  • Quality reports you can show
03 — query

Write SQL that answers things

Once the data is in one place, you need someone to ask it the right questions. I'll write the SQL and the reports.

  • Revenue, delivery, customer reports
  • Performance-tuned queries
  • Documented and repeatable

Questions clients ask

before we start

How do you charge?

Fixed price per project, agreed upfront. Smaller projects can be hourly if you prefer. I'll always tell you the number before I start.

How long does it take?

A typical ETL pipeline takes 1–3 weeks. Small clean-up jobs take a few days. I'll give you a realistic timeline in the plan.

Who owns the code?

You do. Everything I deliver is yours — code, docs, and configuration. No lock-in, no hidden dependencies.

Do you work remotely?

Yes. I work with clients across time zones. Communication via email, Slack, or whatever tool you already use.

What if I don't know exactly what I need?

That's normal — and that's what the first call is for. I'll help you figure out the scope before we commit to anything.

What if the project doesn't work out?

You only pay for completed milestones. If at any point you're not happy, we stop and you keep what's been delivered.

Let's talk data.

Tell me about your data — where it lives, what shape it's in, and what you wish you could do with it. I'll reply within 24 hours with an honest answer about whether I can help.
